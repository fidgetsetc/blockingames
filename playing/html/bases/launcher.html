This game has an issue that we are unable to fix that causes an issue where resizing the game won't make it fit to the screen, and instead in the corner or such.

Before playing,make sure to resize or fullscreen. When done, make sure to click "Start game" below. You can also toggle on Auto-resize to fit the game to future resizes, which is recommended if you resize or exit/enter fullscreen a lot.

Auto-resize Resize the game to the current window and fits that game to future resizes.
