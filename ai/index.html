    How to Get an OpenRouter API Key
    OpenRouter provides access to multiple AI models with a single API. Follow these steps to get started:
    Go to openrouter.ai and click "Sign Up" in the top right.
    You can sign up with email, GitHub, or Google. It's free and takes about 2 minutes.
    Once logged in, click your profile icon in the top right corner, then select "API Keys" from the dropdown menu.
    You'll see your default API key (it starts with "sk-or-"). Click the copy button to copy it to your clipboard.
    Come back here and paste your key in the "OpenRouter API Key" field, then click "Save API Key".
    • You can also save your API key in a .txt file and import it using the "Or Import from File" option

    • OpenRouter supports multiple models: GPT-4, Claude 3, Llama, and many more

    • Free tier includes access to many models with usage credits. Check your account balance at openrouter.ai
